# PID onboarding

An onboarding flow may collect the user's name and a local reference, and never the address or portrait. [policy.json](policy.json) is the purpose policy. [policy-registered.json](policy-registered.json) additionally requires registration evidence, and [registration-names-only.json](registration-names-only.json) is fictional evidence, asserted as verified, that registers only the name fields. In a real deployment, your code builds such evidence only after verifying the registration; see [trust boundaries](../../docs/trust-boundaries.md).

All identifiers are fictional. Run the commands from this directory with the package installed. In a clone of this repository, run `pnpm build` and use `node ../../dist/cli.js` in place of `npx eudi-disclosure`.

| Command                                                                                                                                                                                                                  | Verdict         | Rules                                                      | Why                                                                               |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------- | ---------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `npx eudi-disclosure lint --query requests/names.json --policy policy.json`                                                                                                                                              | `ALLOW`         | —                                                          | Name fields only.                                                                 |
| `npx eudi-disclosure lint --query requests/adds-picture.json --policy policy.json`                                                                                                                                       | `DENY`          | `CLAIM_EXPLICITLY_DENIED`                                  | The portrait is denied for this purpose.                                          |
| `npx eudi-disclosure lint --query requests/names-and-reference.json --policy policy-registered.json --registration registration-names-only.json --rp-id urn:example:rp:shop --service-id urn:example:rp:shop:onboarding` | `DENY`          | `CLAIM_NOT_IN_REGISTERED_SCOPE`                            | The policy allows the reference, but the verified registration covers names only. |
| `npx eudi-disclosure lint --query requests/names.json --policy policy-registered.json`                                                                                                                                   | `INDETERMINATE` | `REGISTRATION_EVIDENCE_MISSING`                            | Registration evidence is required but omitted: not treated as registered.         |
| `npx eudi-disclosure lint --query requests/multiple-vct.json --policy policy.json`                                                                                                                                       | `DENY`          | `CREDENTIAL_TYPE_AMBIGUOUS`, `CREDENTIAL_TYPE_NOT_ALLOWED` | The unknown variant does not inherit permission from the configured type.         |

`expected.json` holds the same table; `pnpm examples` checks every row against the built CLI, including exit codes.
